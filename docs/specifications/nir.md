# NEXUS Intermediate Representation (NIR) v1

NIR is the format-neutral metadata contract in `interfaces/nir`. Its schema version is `1`. PE and ELF parsers produce the same `BinaryMetadata` and `BinarySection` types; format-specific header fields are retained in the tagged `FormatHeaders` value.

## Common metadata

`format` is `pe` or `elf`; `architecture` is `x86`, `x86_64`, `arm`, `aarch64`, or `unknown`. `bitness`, `endianness`, and original `file_size` are explicit. `entry_point` remains the value from the file header and `entry_point_kind` distinguishes a PE RVA from an ELF virtual address. NIR does not silently add the PE image base.

Each section has a stable file-order index, a decoded name, virtual size/address, raw file offset/size, raw format flags, an optional numeric section type (ELF), and normalized read/write/execute booleans. PE raw sizes/offsets come from the section table. ELF `SHT_NOBITS` sections have raw size zero and retain their virtual size; other ELF sections retain their file size/offset.

`headers` is a tagged PE or ELF structure. PE optional-header fields and data directories are preserved. A data directory address identifies whether the value is an RVA or, for the certificate directory, a file offset. ELF identification, class, endian, type, machine, entry, flags, and program/section table metadata are preserved.

## JSON encoding

CLI JSON uses fixed field order, numeric integer fields, lowercase format/architecture/endianness strings, UTF-8 JSON escaping, and source section order. It includes `schema_version`. It contains no timestamps generated by the analyzer, absolute input path, or host-specific state. `inspect` and `info <file>` serialize the full NIR record; `headers` and `sections` return focused objects with the same schema version and format tag.

## Compatibility

Adding optional metadata is an additive schema change. Changing a field's meaning or removing a field requires a new schema version and an ADR. Unknown machine values retain their numeric value in format-specific headers while NIR uses architecture `unknown`.
